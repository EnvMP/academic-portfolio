# Minkyu Park — Academic Research Portfolio

A static, responsive GitHub Pages website containing **20 selected coauthored professional research works** for a Cal Poly Pomona faculty application.

## Contents

- `index.html` — portfolio homepage and 20 selected publication records
- `styles.css` — responsive styling
- `script.js` — category filtering and search
- `favicon.svg` — site icon
- `portfolio.json` — structured citation and DOI reference data
- `.nojekyll` — instructs GitHub Pages to serve this static site without Jekyll processing

No build tools, paid hosting, authentication, or GitHub Actions workflow is required. No publisher PDF files are reproduced.

## Publish to GitHub Pages

1. Sign in to GitHub as `EnvMP`. Create a **public** repository named `academic-portfolio` at https://github.com/new (or pick a different name). When creating it, do not initialize with a README if uploading the contents of this ZIP directly.
2. In the new repository, select **Add file → Upload files**, and upload the files listed above **to the top level (root)** of the repository. Commit the changes to `main`. Alternatively, after the repository is created, ask ChatGPT to push these files using your connected GitHub account.
3. Open **Settings → Pages**. Under **Build and deployment**, set Source to **Deploy from a branch**, branch **main**, and folder **/(root)**, then Save.
4. GitHub Pages will display a **Visit site** link after deployment completes. For a repository named `academic-portfolio` under the `EnvMP` account, the expected project-site URL is `https://envmp.github.io/academic-portfolio/` (verify the live link before using it in the application).
5. Copy the **live** GitHub Pages URL into the Cal Poly Pomona application portfolio field.

GitHub Pages documentation: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

- The retracted Ai Zhang et al. (2019) paper has been excluded.
- The website avoids publishing the candidate's personal mobile phone number, street address, and email.
